## Highlights

Port of the issue #49 contract onto the 1.2.19 heartbeat stack (`dbglog_hb` 4096 + `ring`/`st`/`stk`).

While wall-clock `< 2023-11-14` (`WF_SANE_EPOCH`):

- segment header `started_at` is `0` (relative axis per `ASWF_FORMAT.md`)
- per-row `timestamp` is `0`
- RAM segment registry uses the same `started_at`

Segment age (10 min finalize) **and** the half-age `make_room` trigger use `esp_timer`, not `time(NULL)`. An SNTP or `POST /api/time` jump cannot instantly finalize or evict. `spectrogram_time_synced()` still only rewrites the RAM session anchor.

The extra half-age path is why this is a port, not a raw cherry-pick of `23105d7` (that tree did not have the P-006 timer).
